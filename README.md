# Guild Wars: Reforged — Build Planner

A comprehensive Guild Wars 1 build planning tool featuring:

- **Skill Bar Editor** — Select primary/secondary professions, browse 1400+ skills with filters, drag into 8-slot bar
- **Attribute System** — 200-point allocation with rank scaling and rune bonuses
- **Equipment Planner** — Weapons, armor tiers, insignias, runes with full stat calculations
- **Damage Calculator** — DPS estimates including weapon mastery, inscriptions, and skill contributions
- **Template Import/Export** — Compatible with in-game build template codes
- **Rotation Recommendations** — Auto-generated skill usage order and timing
- **Crafting Materials Guide** — Farm locations, salvage sources, and armor recipes for all tiers
- **Title Track Farming** — Best farms, weekly bonus rotation, GWAMM checklist
- **Elite Skill Locations** — All elites with wiki links to boss capture locations
- **Heroes Guide** — All 31 heroes with unlock requirements and build recommendations
- **Events Calendar** — Annual seasonal events with rewards and farming tips
- **Beginner Tips** — Essential knowledge for new and returning players

## Deployment

This is a static HTML/CSS/JS site — no build step required. Hosted via GitHub Pages.
